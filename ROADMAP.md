# План развития mytracker

План отражает текущее направление проекта. Архитектуру, API и формат хранения будем уточнять по мере появления требований, а не фиксировать заранее.

## Уже реализовано в прототипе

- Настольное приложение для Windows на Kotlin/JVM и Compose Multiplatform.
- Главный экран, каталог и категории «Фильмы», «Аниме», «Сериалы».
- Группировка каталога по статусам: «Хочу посмотреть», «Просмотрено», «Брошено».
- Добавление и удаление произведений; подтверждение удаления.
- UI разделён по ответственности: корневая композиция приложения, экраны каталога, карточка произведения, форма добавления и общие компоненты находятся в отдельных файлах.
- Изменение статуса, оценки и рецензии с сохранением по кнопке «Готово» и отменой по кнопке «Назад».
- Личные заметки с системной датой; заметки можно добавлять и удалять.
- Сезоны сериалов загружаются из TMDB; у всего сериала и отдельных сезонов есть независимые необязательные оценки и рецензии.
- Динамический универсальный поиск фильмов и сериалов через TMDB независимо от выбранной категории: прямой запрос после 300 мс паузы, затем — поиск вариантов написания после 1500 мс, если прямой поиск пуст. Выбранный тип только приоритизируется; тип результата автоматически определяет категорию. Поддерживаются варианты `е/ё`, неверная раскладка, русская транслитерация латиницей и диакритика. Для `429` действует адаптивное увеличение задержки.
- Раздельные категории для обычных фильмов/сериалов и аниме-фильмов/сериалов. Категория аниме определяется автоматически по ключевым словам TMDB либо по сочетанию жанра анимации и японского языка/происхождения; категорию всегда можно изменить вручную.
- Результаты TMDB выводятся прямо под полем названия вместе с постерами; список результатов прокручивается отдельно от всей карточки добавления. Выбранный результат сохраняет внешний ID, тип записи, URL постера, год и страны производства; эти данные показываются рядом с названием в каталоге. Постер виден в каталоге и карточке произведения и открывается крупнее по нажатию. В свёрнутом блоке выбора показываются название, год и страна производства.
- Для новых произведений используются UUID; перед добавлением ID проверяется на совпадение с уже существующими в каталоге.
- Локальное файловое хранилище единого формата версии 8 с проверками чтения и записи; версия 7 однократно мигрируется при загрузке.
- Ошибки чтения и записи каталога показываются пользователю с причиной и путём к файлу. Если каталог не удалось прочитать, запись заблокирована; неуспешное сохранение не меняет состояние в интерфейсе и оставляет исходный файл.

## Развитие интеграции TMDB

- Источник выбран: TMDB для фильмов, сериалов и аниме. Поиск для аниме проверяет каталоги фильмов и сериалов, поскольку TMDB не выделяет аниме в отдельный тип.
- [x] Подгружать метаданные сезонов для записей типа `tv`; показывать название, число эпизодов и дату премьеры, если они доступны. Ручное создание сезонов не планируется.
- Поэтапно дополнять интерфейс метаданными TMDB: показывать в списке каталога и карточке произведения год, описание, жанры и другие полезные данные; определить состояния загрузки и отсутствующих метаданных. Кэшировать метаданные, не смешивать внешние рейтинги с личной оценкой и сохранять локальный каталог доступным без сети.
- Добавить понятное восстановление после сетевых ошибок TMDB, например повтор запроса. Поиск уже показывает ошибки TMDB и при `429` увеличивает задержку; локальный каталог уже загружается из файла и доступен без сети.
- Перед распространением приложения проверить требования TMDB к ключам API и атрибуции.
