# mytracker

Личный каталог фильмов, аниме и сериалов на Kotlin Multiplatform и Compose Multiplatform. Целевая платформа приложения — настольная Windows/JVM.

## Возможности

- Главный экран со сводкой по коллекции.
- Каталог всех произведений и разделы «Фильмы», «Аниме» и «Сериалы».
- Группировка записей по статусам: «Хочу посмотреть», «Просмотрено», «Брошено».
- Добавление произведения через динамический поиск TMDB или вручную, с категорией, статусом и личной заметкой.
- Для статуса «Просмотрено» требуется оценка от 1 до 5.
- Редактирование статуса, оценки, рецензии и личных заметок. В карточке «Готово» сохраняет изменения, а «Назад» отменяет их.
- Заметки о просмотре с системной датой. В интерфейсе дата отображается в формате `ДД.ММ.ГГГГ`.
- Просмотр сезонов и заметки к ним. Ручное добавление сезонов пока не поддерживается.
- Удаление произведений с подтверждением и удаление личных заметок.
- Локальное сохранение каталога между запусками.

Поиск использует TMDB API. Результаты прямого поиска обновляются через 300 мс после паузы во вводе. Если прямой поиск ничего не нашёл, через 1500 мс запускается поиск с вариантами написания: `е/ё`, другая раскладка клавиатуры, русская транслитерация и буквы с диакритикой. Результаты показываются под полем названия; список результатов прокручивается независимо от остальной карточки.

При ответе TMDB `429 Too Many Requests` пауза прямого поиска увеличивается; после успешных запросов она постепенно возвращается к исходным 300 мс. Для фильмов и сериалов используются соответствующие каталоги TMDB, а для категории «Аниме» проверяются оба. После выбора результата в карточке добавления показываются название, год выпуска и страна производства. Страна загружается из подробностей TMDB; для сериалов используется страна происхождения, если список стран производства отсутствует. Выбранный результат сохраняет внешний идентификатор и тип записи (`movie` или `tv`). Личные статусы, оценки и заметки остаются данными приложения. Загрузка сезонов и остальные метаданные из API пока не подключены.

Для доступа к API нужен токен **API Read Access Token** из настроек API аккаунта TMDB. Для запуска из PowerShell задайте его в переменной среды:

```powershell
$env:TMDB_API_READ_ACCESS_TOKEN = 'ваш токен'
.\gradlew.bat run
```

В IntelliJ IDEA укажите `TMDB_API_READ_ACCESS_TOKEN` в переменных среды конфигурации запуска. Не добавляйте токен в файлы проекта или Git.

Для некоммерческого использования приложение показывает официальную атрибуцию TMDB в разделе «О приложении». Актуальные требования приведены в [документации TMDB](https://developer.themoviedb.org/docs/faq).

## Хранение данных

Каталог хранится в файле `~/.mytracker/catalog.dat` в домашней папке пользователя. В Windows это обычно `%USERPROFILE%\.mytracker\catalog.dat`.

Формат файла версионируется. При загрузке старых версий сохраняются поддерживаемые данные и выполняются необходимые миграции. Запись выполняется через временный файл с последующей заменой основного. При ошибке чтения приложение показывает причину и путь к файлу и блокирует запись, чтобы не затереть каталог пустыми данными. При ошибке записи приложение сообщает причину, оставляет прежнее состояние каталога и сохраняет исходный файл.

## Требования

- JDK 25 для настроенного Gradle toolchain.
- Gradle Wrapper загружает Gradle 9.8.2 автоматически.

JVM-байткод проекта нацелен на Java 21. Wrapper запускается с Java, указанной через `JAVA_HOME` или `PATH`.

## Запуск из PowerShell

Укажите `JAVA_HOME` на установленный JDK, затем из корня проекта выполните:

```powershell
$env:JAVA_HOME = 'C:\путь\к\JDK'
$env:Path = "$env:JAVA_HOME\bin;$env:Path"
.\gradlew.bat run
```

В IntelliJ IDEA выберите Gradle JVM в **Settings → Build, Execution, Deployment → Build Tools → Gradle** и запустите Gradle-задачу `run`.

## Тесты

Запустить JVM-тесты из PowerShell:

```powershell
.\gradlew.bat jvmTest
```

Тесты проверяют файловое хранилище: чтение пустого каталога, сохранение и загрузку записей и вложенных данных, перезапись, пустой каталог, миграцию старых версий и сохранность файла при ошибках чтения и записи. Также проверяется генерация ID. Автоматические UI-тесты пока не настроены.

## Структура проекта

- `src/commonMain` — Compose-интерфейс и общие модели данных.
- `src/jvmMain` — JVM-точка входа и локальное файловое хранилище.
- `src/jvmTest` — JVM-тесты хранилища.
- `gradle/wrapper` — версия Gradle Wrapper.
